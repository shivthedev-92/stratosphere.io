Stratosphere Productivity App

Project workflow, feature summary, and current product scope

Prepared on 12 May 2026

Product idea: Stratosphere is a productivity and reflection app that helps users plan daily action items, add journal reflections, understand emotional context, and receive task-aware support from an AI life coach.

1. Project Overview

The project currently has three main surfaces: a web application, a React Native mobile app, and a FastAPI backend. The web app includes the authenticated productivity experience and a promotional site. The mobile app is the iPhone-first experience for daily task management. The backend stores users, tasks, journal entries, notifications, chat history, and support tickets.

Layer Technology Role
Backend FastAPI, SQLAlchemy, Alembic, PostgreSQL Authentication, profile, tasks, journal logs, notifications, AI chat, support tickets.
Web frontend Next.js, TypeScript, Tailwind CSS Promotional site, login/signup, dashboard, task workflow, AI coach, contact/support.
Mobile app Expo React Native, TypeScript iPhone-focused task workflow, calendar, journal, notifications, profile settings, AI assistant.
AI assistant Ollama through FastAPI Task-aware coaching based on user action items and recent reflections.

2. Core User Workflow

2.1 Account and access

  • User signs up or logs in from the web app.
  • Mobile app uses the same backend account and token-based authentication.
  • User profile includes name, phone number, date of birth, and in-app notification preference.
  • Profile settings are available inside the app experience, with support/contact nested there.

2.2 Daily planning

  • User creates an action item with title, notes, emoji, priority, optional calendar date, and optional time.
  • Tasks can be low, medium, or high priority, with colored badges and priority dots on calendar days.
  • Today, All, and Completed views help the user filter their current task list.
  • Calendar day selection opens a day-level view with all action items for that date.

2.3 Task journal

  • User opens a task and adds journal entries over time.
  • Each journal entry can include reflection text, meaningfulness, and an emotion label.
  • The task journal displays entries as a vertical timeline.
  • Completed tasks no longer accept new reflections; users can review or delete them.

2.4 Completion flow

  • Journal entries capture reflections, feelings, and progress context.
  • Task completion is explicit at the task level using done/not-done status.
  • Completed tasks are shown separately in the Completed section.

5. Backend Capabilities

  • User authentication and token-based access control.
  • User profile fields: name, phone number, date of birth, and notification preference.
  • Goal/action item CRUD with priority, schedule, emoji, and completion fields.
  • Goal logs for journal reflections, meaningfulness, and emotion labels.
  • In-app notifications with read, due, and acknowledgement states.
  • Persistent AI chat sessions and messages.
  • Support tickets submitted from public website, web app settings, or mobile settings.
  • Alembic migrations maintain database evolution.

6. AI Assistant Workflow

The AI assistant sends user messages to the FastAPI backend. The backend gathers relevant task and reflection context, then calls the local Ollama model. Responses are returned to the client and persisted in chat sessions so users can resume previous conversations.

  • General assistant chat can reference current action items and recent reflections.
  • Task-specific robot buttons open a conversation focused on an individual task.
  • Chat sessions are stored and resumable.
  • Production deployment still needs a final AI hosting decision.

7. Contact and Support Workflow

The promotional website keeps a public Contact us form for prospects or unauthenticated visitors. Inside the app, support is intentionally placed under profile/settings so tickets are tied to authenticated users and reduce irrelevant submissions.

Context Support entry point
Promotional website Public Contact us page and form.
Authenticated web app Profile settings modal, then Contact us section.
Mobile app Settings screen, then Contact us section.
